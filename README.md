# BMI 小網頁 / BMI Web App (v2 中英雙語 / Bilingual)

一個簡單的 BMI（身體質量指數 / Body Mass Index）計算器網頁，支援中文與英文切換。

A simple BMI calculator web app with Chinese/English language switching.

## 使用方式 / Usage

直接以瀏覽器開啟 `index.html`，或透過本機伺服器提供。

Open `index.html` in a browser, or serve it with a local web server.

## 計算公式 / Formula

BMI = 體重(kg) / 身高(m)^2

分類參考（成人）/ Adult BMI reference:
- 過輕 / Underweight: < 18.5
- 正常 / Normal: 18.5 – 24
- 過重 / Overweight: 24 – 27
- 肥胖 / Obese: ≥ 27
